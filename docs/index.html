How it fits together

  1. You
  2. →

  5. baw-dev-tools MCP server
  6. →
  7. BAW Operations REST API

Bob writes three kinds of files: app specs (work/*.app.json), coach specs (work/*.coaches.json) and React screens (react-coach/src/screens/*.jsx). The server does the platform work: it builds .twx files, installs them, reads coaches and tests every screen in a headless browser.

coach-modernizeWrites a screen per coach, adds the React versions as a new snapshot, installs and tests them

Guard rails

  • Only apps whose name and acronym start with "ZZ" can be installed.
  • A snapshot name can be used once per app; BAW would otherwise keep the old content silently.
  • There is no delete tool.
  • Credentials stay in the server process and are never returned to the agent.
