What is in each toolkit
App Builder Widgets ABWTheme, App Header, Section, Review List, Button Bar. Plain BAW markup, no framework; the fields inside stay UI Toolkit views.
Modernizer Widgets MDWTheme, Header, Error Summary, Text Field, Text Area, Number Field, Date Field, Checkbox, Select, Radio Group, Button. React + Carbon.5
